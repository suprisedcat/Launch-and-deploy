# App Store Screenshots

This folder is for your app store screenshots.

## Required Screenshots

### iOS App Store
- **6.7" iPhone** (iPhone 15 Pro Max): 1290x2796 pixels
- **6.5" iPhone** (older models): 1284x2778 pixels
- **12.9" iPad Pro** (if supporting iPad): 2048x2732 pixels
- **Quantity**: 3-10 screenshots per device size

### Google Play Store
- **Phone**: 1080x1920 pixels (or 16:9 aspect ratio)
- **7" Tablet**: 1200x1920 pixels
- **10" Tablet**: 1600x2560 pixels
- **Quantity**: Minimum 2 screenshots, maximum 8

## Tips for Great Screenshots

1. **Show Real Content**: Use actual app screens, not mockups
2. **Highlight Key Features**: Showcase what makes your app unique
3. **Add Captions**: Brief text overlays explaining features
4. **Use Consistent Branding**: Match your app's color scheme
5. **Show Diverse Use Cases**: Different scenarios and screens
6. **Test on Devices**: View at actual size to ensure readability

## How to Take Screenshots

### On iOS Simulator
```bash
# Run your app in simulator
npx expo start --ios

# Take screenshot: Cmd + S
# Screenshots saved to Desktop
```

### On Android Emulator
```bash
# Run your app in emulator
npx expo start --android

# Take screenshot: Cmd + S (Mac) or Ctrl + S (Windows)
# Screenshots saved to Desktop
```

### On Physical Devices
- **iOS**: Power button + Volume Up
- **Android**: Power button + Volume Down

## Naming Convention

Use descriptive filenames:
- `01-home-screen.png`
- `02-main-feature.png`
- `03-user-profile.png`
- `04-settings.png`
